توجيهات تشغيل متجر حبيبة ستور (تحديث ٤ — دعم الفيديو)
------------------------------------------------------------

جديد في هذا التحديث:
- لوحة التحكم بقى فيها حقل "فيديو المنتج" اختياري جنب حقل الصورة، ترفعيه زي ما بترفعي الصورة بالظبط.
- في صفحة المتجر، لو المنتج له فيديو هيظهر زرار تشغيل ▶ صغير على صورة المنتج، الزبونة تدوسي عليه يشتغل الفيديو مكان الصورة.
- ملحوظة مهمة: الفيديوهات بتاخد مساحة تخزين وبيانات (bandwidth) أكتر بكتير من الصور على Firebase،
  والخطة المجانية (Spark) بتدي 5 جيجا تخزين و1 جيجا bandwidth يوميًا بس. حاولي تضغطي الفيديو وتخليه
  قصير (كام ثانية بس تكفي) قبل الرفع عشان ميستهلكش الحصة المجانية بسرعة. حطيت حد أقصى لحجم الفيديو
  الواحد 40 ميجا في قواعد التخزين (storage.rules).

التحديثات اللي قبل كده:
- تحديث الخط: بقى الموقع ولوحة التحكم بيستخدموا خط Baloo Bhaijaan 2 (للعناوين) وTajawal (للنصوص).
- تحديث التصميم: الحواف كلها (الأزرار، الحقول، صور المنتجات، الإشعارات) بقت مدورة شوية بدل الحواف الحادة.
- توضيح خاص بلوحة التحكم ورفع الملفات عن طريق GitHub — اقرأي القسم رقم 2 و3 تحت كويس، فيه خطوة ضرورية جدًا (إضافة نطاق GitHub في Firebase) من غيرها تسجيل الدخول في اللوحة مش هيشتغل.

------------------------------------------------------------
1. فين لوحة التحكم؟
------------------------------------------------------------
لوحة التحكم هي ببساطة ملف admin-login.html. مفيش رابط "سري" لازم تفتكريه —
بعد ما ترفعي الموقع، هتلاقيها على:

   https://[عنوان موقعك]/admin-login.html

مثال: لو موقعك بقى شغال على
   https://habibaali.github.io/habiba-store/
هتفتحي اللوحة من
   https://habibaali.github.io/habiba-store/admin-login.html

(ملحوظة: كان فيه رابط قديم شكله /admin/Zyyalla@1 — ده كان بيشتغل بس لو الموقع مرفوع
على Firebase Hosting تحديدًا، لأنه معتمد على إعداد جوه ملف firebase.json. دلوقتي إنتِ
هترفعي على GitHub، فالرابط ده مش هيشتغل، واستخدمي admin-login.html مباشرة زي فوق.)

------------------------------------------------------------
2. خطوة ضرورية: إضافة نطاق GitHub في Firebase (من غيرها الدخول مش هيشتغل)
------------------------------------------------------------
تسجيل دخول الأدمن بيعتمد على Firebase Authentication، وFirebase بيرفض أي محاولة
تسجيل دخول جاية من موقع مش معروف له، فلازم تضيفي عنوان GitHub بتاعك يدويًا:

   أ- روحي لـ Firebase Console -> مشروعك (habiba-store-e70d2).
   ب- Build -> Authentication -> تبويب Settings -> Authorized domains.
   ج- دوسي "Add domain" وضيفي عنوان موقعك من غير https:// وبدون أي مسار بعده، مثال:
      habibaali.github.io
   د- احفظي.

من غير الخطوة دي هتظهرلك رسالة خطأ (auth/unauthorized-domain) ومش هتقدري تدخلي اللوحة خالص.

------------------------------------------------------------
3. رفع الملفات على GitHub (GitHub Pages)
------------------------------------------------------------
   أ- روحي على GitHub وسوّي Repository جديد (Public)، مثلاً باسم habiba-store.
   ب- ارفعي فيه كل الملفات اللي في مجلد public (index.html, admin-login.html,
      logo.png, favicon.png) — ارفعيهم في جذر الـ Repository مباشرة (من غير ما
      تحطيهم جوه مجلد public تاني، عشان GitHub Pages بيقرأ من الجذر بشكل افتراضي).
   ج- من إعدادات الـ Repository: Settings -> Pages -> اختاري:
      Branch: main (أو master) — Folder: / (root)
      واحفظي.
   د- بعد دقيقة أو اتنين، هيظهرلك رابط موقعك تحت في نفس الصفحة، شكله:
      https://[اسم حسابك].github.io/habiba-store/

   ملحوظة: ملفات firebase.json وfirestore.rules وstorage.rules مش هترفعيهم على
   GitHub Pages — دول مش لازمين إلا لو قررتِ تستخدمي Firebase Hosting بدل GitHub
   في يوم من الأيام. قاعدة قاعدة البيانات (Firestore) وقاعدة التخزين (Storage)
   هتفضل شغالة عادي زي ما هي دلوقتي حتى لو الموقع نفسه مرفوع على GitHub، لأنهم
   خدمة منفصلة في Firebase مش متعلقة بمكان استضافة ملفات الـ HTML.

------------------------------------------------------------
4. لو لسه معملتيش حساب الأدمن (Firebase Authentication)
------------------------------------------------------------
   أ- Firebase Console -> Build -> Authentication -> Sign-in method -> فعّلي Email/Password.
   ب- من تبويب Users -> Add user -> حطي بريد وكلمة مرور قوية (منك اختيارهم).
   ج- بيهم تقدري تسجلي دخول من admin-login.html.

------------------------------------------------------------
5. قواعد الأمان (لو مستخدماها فعلاً على Firebase)
------------------------------------------------------------
Firestore -> Rules -> الصقي محتوى ملف firestore.rules.
Storage -> Rules -> الصقي محتوى ملف storage.rules.
